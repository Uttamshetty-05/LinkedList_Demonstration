# 🚀 Linked List Visualizer Pro

An interactive and animated web-based Linked List Visualizer built using HTML, CSS, and JavaScript.

## 📌 Features

* Insert Node at Beginning
* Insert Node at End
* Delete Node
* Search Node
* Reverse Linked List
* Find Middle Node
* Count Total Nodes
* Clear Entire List
* Operation History Tracking
* Animated Node Visualization
* Responsive Dark Theme UI
* Node Highlighting on Search
* User-Friendly Status Messages

## 🖥️ Preview

```text
HEAD ↓

[10] → [20] → [30] → NULL
```

## 🔍 Search Functionality

When an element is found:

```text
✓ Element 20 found
```

When an element is not found:

```text
✗ Element 20 not found in Linked List
```

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Uttamshetty-05/LinkedList_Demonstration.git
```

2. Open the project folder

3. Open `index.html` in your browser

OR

Use VS Code Live Server:

* Install Live Server extension
* Right Click → Open with Live Server
